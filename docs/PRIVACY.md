# Данные, которые хранит AntiTerror Robot

Сервис нужен, чтобы человек сам зафиксировал ситуацию и получил памятку для обращения в МВД. Это не полиция и не канал передачи заявлений.

## Что сохраняется

Пользователь сам вводит:

- категорию и описание;
- примерное время, площадку и публичную ссылку;
- необязательные обозначения аккаунта, с которого пришло сообщение;
- описание требований;
- файлы разрешённых типов;
- необязательный контакт для уточнения карточки.

Рядом хранится числовой Telegram id владельца карточки, чтобы чужой человек не открыл её по короткому номеру. Имя, фото и username из Telegram не записываются.

Короткий номер карточки `ATR-…` случайный и сам по себе не указывает на человека.

## Чего сервис не принимает

Форма и API отклоняют пароли, коды из СМС, CVV, номера банковских карт и длинные номера счетов. Интимные материалы загружать нельзя: для фиксации шантажа достаточно описать факт, без самих файлов. Автоматическая проверка не умеет надёжно узнавать такие изображения, поэтому удаление доступно пользователю и модератору.

## Контакт

Если человек согласился оставить контакт, значение шифруется перед записью. В ответах API и в PDF видна только маска.

## Срок и удаление

Карточки и файлы хранятся 180 дней, отметки об открытии срочной помощи — 30 дней. Затем фоновое задание их удаляет. На экране карточки есть удаление по запросу: описание, контакт и файлы стираются сразу.

Сервис не публикует карточки и не отправляет их в МВД. Кнопка «отправить копию» пишет PDF только в личный чат того же пользователя с ботом.

## Кто видит карточку

Владелец видит свою карточку. Модератор и администратор видят её, чтобы проверить полноту и соблюдение правил, а не чтобы расследовать человека. Их действия смены статуса и ролей пишутся в аудит без текста описания.
