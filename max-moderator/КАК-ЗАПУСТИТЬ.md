# Как запустить бота с нуля

Это короткая инструкция. Компьютер должен быть включён, пока бот работает: MAX сам бота не хранит, программа крутится у вас.

Пока бот запущен, он сам забирает новые сообщения. Отдельный сайт и белый IP для первой проверки не нужны.

## Что подготовить

1. Компьютер с Windows, macOS или Linux.
2. Приложение [Docker Desktop](https://www.docker.com/products/docker-desktop/). После установки откройте его и дождитесь, пока оно напишет, что запущено. На Windows может понадобиться перезагрузка.
3. Аккаунт организации, ИП или самозанятого на [платформе MAX для партнёров](https://dev.max.ru). Обычного личного аккаунта MAX для создания бота недостаточно: так написано в документации MAX.
4. Групповой чат, где вы администратор, и второй аккаунт обычного участника. Свой собственный аккаунт для проверки не подойдёт: бот не удаляет сообщения владельца и администраторов.

## 1. Скачайте проект

В терминале (на Windows это PowerShell):

```bash
git clone https://github.com/evgeniiivanov2026-prog/antiterror_robot.git
cd antiterror_robot
git checkout cursor/max-moderation-bot-c7d5
cd max-moderator
```

Папка `max-moderator` — это и есть бот. Остальные папки репозитория для запуска не нужны.

## 2. Создайте бота и скопируйте токен

1. Откройте платформу MAX для партнёров, раздел «Чат-боты».
2. Создайте бота.
3. У этого бота нажмите `⋮` → «Настройки».
4. Скопируйте токен кнопкой рядом с полем токена.

Токен — это длинный секрет. Его можно вставить только в файл `.env` на вашем компьютере. В чат, на почту и в скриншоты его отправлять не нужно.

## 3. Разрешите добавлять бота в группы

У нового бота добавление в группы выключено. Пока вы его не включите, в списке участников бота не будет. В личный диалог бота добавить нельзя, только в групповой чат.

Сначала дождитесь модерации. Статус написан рядом с названием бота на платформе. Настройку приватности MAX открывает только после модерации.

Потом:

1. Платформа MAX для партнёров → «Чат-боты».
2. Нужный бот → `⋮` → «Настройки».
3. Раздел «Приватность».
4. Включите добавление в групповые чаты и нажмите «Сохранить».

В самом MAX откройте бота по ссылке `https://max.ru/ник_бота` и нажмите «Начать». После этого вернитесь в группу.

## 4. Впишите токен

В папке `max-moderator` выполните:

Windows:

```powershell
copy .env.example .env
notepad .env
```

macOS или Linux:

```bash
cp .env.example .env
```

Откройте файл `.env` любым редактором. Первая строка должна стать такой:

```env
MAX_BOT_TOKEN=сюда_вставьте_токен
```

Без кавычек и без пробела после `=`. Остальные строки не меняйте.

Строку `ADMIN_IDS` оставьте пустой. Команды и так доступны владельцу и администраторам чата.

## 5. Запустите

На сервере, в папке `max-moderator`, выполните:

```bash
bash up.sh
```

Скрипт сам скачает образ и соберёт бота старым сборщиком Docker. Так не возникает ошибка `no active session` / `DeadlineExceeded`: Docker не успел скачать слой образа.

Строки `bookworm InRelease` и `bookworm-updates InRelease` — это список пакетов Debian 12. Если рядом написано `Connection timed out` и адрес `199.232.174.132`, сервер не открывает сайт Debian. Из-за пустого списка `apt` затем пишет, что `ca-certificates` и `openssl` не найдены. В актуальном Dockerfile эти пакеты не скачиваются: они уже лежат внутри образа Node.js.

Если скрипта ещё нет, вставьте команды вручную:

```bash
docker pull node:22-bookworm-slim
export DOCKER_BUILDKIT=0
export COMPOSE_DOCKER_CLI_BUILD=0
export COMPOSE_BAKE=false
docker compose build
docker compose up -d
```

Первый запуск может занять несколько минут. Бот готов, когда в журнале есть строка `starting max long polling`. Журнал:

```bash
docker compose logs -f bot
```

Остановить бота:

```bash
docker compose down
```

Запустить снова в фоне, чтобы терминал можно было закрыть:

```bash
docker compose up -d
```

Повторный `--build` на этом сервере снова включает сборщик, который падает с `DeadlineExceeded`. Если меняли код бота, запускайте `bash up.sh`.

Смотреть журнал:

```bash
docker compose logs -f bot
```

## 6. Добавьте бота в чат

Это групповой чат, не личная переписка. Добавлять должен администратор группы.

1. Откройте групповой чат в MAX.
2. Нажмите на название чата вверху.
3. «Участники» → «Добавить участников».
4. Найдите бота по нику и подтвердите.
5. В настройках чата откройте «Администраторы» → «Добавить администратора» → выберите бота.
6. Включите «Читать сообщения». Потом включите удаление сообщений. Пока чтение выключено, удаление отметить нельзя.

Если бота нет в поиске, вернитесь к шагу 3: модерация, галочка приватности и кнопка «Начать» в диалоге с ботом.

## 7. Проверьте, что он живой

С аккаунта администратора напишите в чат:

```text
/start
```

Бот ответит списком команд. Затем:

```text
/filter add "куплю базу данных"
```

Бот ответит, что фильтр добавлен, и покажет его номер.

Теперь с **другого** аккаунта, который не администратор, отправьте:

```text
куплю базу данных
```

Сообщение исчезнет. С аккаунта администратора команда `/audit` покажет, что бот его удалил.

Сообщение администратора с этими же словами бот не трогает. Это нормально.

## Если что-то пошло не так

| Что видите | Что сделать |
| --- | --- |
| `no active session` или `DeadlineExceeded` при сборке | Выполните команды из шага 5: `bash up.sh`. Обычный `docker compose up --build` на сервере часто падает на скачивании образа |
| `Connection timed out` и `deb.debian.org`, затем `no installation candidate` | Обновите код (`git pull`) и снова выполните `bash up.sh`. Сервер не открывает сайт Debian, поэтому старый Dockerfile не может скачать пакеты |
| `ECONNRESET` и `registry.npmjs.org` много минут | Сайт npm обрывает скачивание. Нажмите `Ctrl+C`, выполните `git pull` и снова `bash up.sh`. Сборка перейдёт на зеркало |
| Бота нет в поиске участников | На платформе партнёров включите приватность «добавление в групповые чаты». Пункт появляется после модерации. Затем в MAX откройте бота и нажмите «Начать» |
| `MAX_BOT_TOKEN is required` | В `.env` пустой токен или файл лежит не в папке `max-moderator` |
| В журнале `401` или `Invalid access_token` | Токен скопирован с пробелом, кавычками или не целиком. Вставьте его заново и выполните `bash up.sh` |
| `/start` молчит | Бот не администратор, выключено чтение всех сообщений, или программа на сервере уже остановлена |
| «Команда доступна только администраторам» | Пишет обычный участник. Команды настройки отправляет владелец или администратор чата |
| Запрещённое слово не удалилось | Его отправил владелец, администратор или человек из белого списка. Попросите написать обычного участника |
| В журнале `403` | Боту не включили право писать и удалять сообщения |

Подробности для разработчиков остаются в [README.md](README.md).
