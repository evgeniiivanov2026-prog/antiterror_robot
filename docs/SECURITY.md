# Безопасность

## Граница сервиса

AntiTerror Robot фиксирует рассказ пользователя. Он не выносит оценок виновности, не обещает проверку и не связывается с полицией от имени человека.

## Доступ

- Все внешние запросы идут через Nginx по HTTPS. В production API без заголовка `X-Forwarded-Proto: https` отвечает 403, кроме проверки живости.
- Порт backend не публикуется в Compose. Доверять заголовку протокола можно только если до backend нельзя достучаться в обход Nginx.
- Mini App передаёт заголовок `Authorization: tma <initData>`. Сервер проверяет HMAC-SHA256 ключом бота и срок `auth_date`. Поля с клиента, которых нет в подписи, не принимаются.
- `ALLOW_DEV_AUTH` работает только в `development` и `test`. В `production` процесс не стартует, если флаг включён, база не PostgreSQL, нет токена бота или адрес Mini App не начинается с `https://`.

## Данные

- Секреты читаются из окружения. В репозитории есть только `.env.example` без настоящих значений.
- Контакт шифруется Fernet. Ключ — `ENCRYPTION_KEY`.
- Ссылки проверяются как публичные `http`/`https`. Сервер их не скачивает, поэтому не ходит во внутренние адреса.
- Загрузка ограничена по числу, размеру и типу. Сравниваются заявленный MIME и сигнатура файла. Исполняемые файлы, HTML, SVG и PDF с активными действиями отклоняются. Если задан `CLAMAV_HOST`, загрузка дополнительно идёт в ClamAV и при недоступности сканера не сохраняется.
- Ключ файла генерирует сервер. Имя с клиента в хранилище не используется.
- Журнал — JSON. В него не пишутся тело запроса, описание, контакт и токен бота. Случайный токен в тексте сообщения маскируется.

## Злоупотребления

- Создание карточек, чтение, загрузка и экспорт ограничены по Telegram id. В production счётчик хранится в Redis.
- Ошибка лимита не скрывает телефоны 112 и 102: экран срочной помощи показывает их даже без ответа API.
- Роли: `user`, `moderator`, `admin`. Пользователь может только отметить, что сохранил карточку для обращения в МВД. Статус проверки полноты ставит модератор. Смена ролей доступна администратору и пишется в аудит.
- Одинаковая ошибка 404 не даёт отличить чужую карточку от несуществующей.

## Локальный TLS

Compose выпускает самоподписанный сертификат для `localhost`. Для публичного адреса нужен настоящий сертификат; заголовок HSTS стоит включать уже на боевом домене, а не на локальном сертификате.
