# Безопасность

AntiTerror Robot принимает сообщение от человека и помогает ему сохранить карточку. Он не расследует происшествие, не выносит оценку человеку и не обещает, что МВД примет заявление.

## Границы

- Все запросы к API в промышленном контуре принимаются только по HTTPS. В локальном Docker это отключено, чтобы можно было открыть `http://localhost:8080`.
- Личность берётся из подписи Telegram `initData`. Поля, которые прислал браузер, не считаются доказательством того, кто пользователь.
- `ALLOW_DEV_AUTH` работает только при `ENVIRONMENT=development` или `test`. В production процесс не стартует, если флаг включён.
- Входные данные проходят через схемы Pydantic. Статус карточки и её владельца клиент задать не может.
- Ссылки сохраняются как текст и не запрашиваются сервером. Адреса localhost, частные и служебные IP отклоняются.
- Контакт автора шифруется ключом `CONTACT_ENCRYPTION_KEY`.
- Файлы ограничены по размеру и типу. Проверяются сигнатуры байтов. Исполняемые файлы, архивы, HTML и SVG не принимаются. Если задан `CLAMAV_HOST`, файл дополнительно уходит в ClamAV; при недоступном сканере загрузка отклоняется.
- Распознавания лиц и интимных изображений нет. Запрет на такие файлы держится на правиле и подтверждении пользователя. Это ограничение нужно понимать прямо: сервис не умеет увидеть, что на картинке.
- Частота созданий карточек, загрузок и чтений ограничивается. В production для этого нужен Redis. Если Redis на мгновение недоступен, используется запасной счётчик процесса, чтобы обращение не пропало.
- Ошибки возвращаются одним JSON и не содержат текст исключения.

## Роли

- `user` создаёт и читает только свои карточки.
- `moderator` может перевести статус `new`, `under_review`, `forwarded`, `closed`. Статус `forwarded` значит, что человеку подсказали обратиться в МВД. Сервис ничего никуда не отправляет.
- `admin` дополнительно может удалить чужую карточку. Смена статуса и удаление пишутся в журнал.

Идентификаторы ролей задаются `MODERATOR_IDS` и `ADMIN_IDS`.

## Секреты

`BOT_TOKEN`, `DATABASE_URL`, ключи S3 и ключ шифрования не хранятся в репозитории. Пример имён переменных — в `.env.example`. Производственный запуск отказывается стартовать с локальными паролями и коротким ключом шифрования.

## Что это не гарантирует

Файл мог быть изменён до загрузки. Карточка не является доказательством, принятым судом или полицией. PDF — удобная выгрузка для личного обращения, а не заключение.
