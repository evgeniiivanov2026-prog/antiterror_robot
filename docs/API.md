# API

Базовый путь: `/api/v1`. Ошибки всегда имеют вид:

```json
{
  "error": {
    "code": "validation_error",
    "message": "Проверьте введённые данные",
    "details": []
  }
}
```

Авторизованные методы ждут заголовок `Authorization: tma <initData>`.

## Методы

| Метод | Путь | Кто | Назначение |
| --- | --- | --- | --- |
| GET | `/health` | все | Процесс жив |
| GET | `/ready` | все | База отвечает |
| GET | `/meta/categories` | все | Категории и дисклеймер |
| POST | `/reports` | автор | Создать карточку |
| GET | `/reports/{public_id}` | автор | Своя карточка по номеру `ATR-……` |
| POST | `/reports/{id}/evidence` | автор | Загрузить файл |
| POST | `/reports/{id}/export` | автор | PDF для обращения |
| POST | `/reports/{id}/send-to-chat` | автор | Короткая копия в чат бота |
| POST | `/reports/{id}/mark-referred` | автор | Отметить, что человек сам обратился в МВД |
| DELETE | `/reports/{id}` | автор | Удалить карточку и файлы |
| GET | `/me` | автор | Роль `user`, `moderator` или `admin` и свой числовой id |
| DELETE | `/me` | автор | Удалить все свои данные |
| POST | `/emergency` | автор | Зафиксировать открытие срочной помощи |
| GET | `/moderation/reports` | модератор | Очередь без текста и контакта |
| GET | `/moderation/reports/{id}` | модератор | Карточка без расшифрованного контакта |
| POST | `/moderation/reports/{id}/close` | модератор | Закрыть спам или отметить полноту |
| POST | `/telegram/webhook` | Telegram | Приём обновлений, если `BOT_MODE=webhook` |

`{id}` — UUID карточки. `{public_id}` — короткий номер вида `ATR-7K2M9Q`. Чужая карточка отвечает как «не найдена».

## Создание карточки

```json
{
  "category": "fraud",
  "description": "Незнакомец просил перевести деньги за заказ, которого не было.",
  "occurred_at": "2026-10-30T12:00:00Z",
  "platform": "Telegram",
  "source_url": "https://t.me/example",
  "suspect_identifiers": {"username": "example_user"},
  "demands": {"summary": "Просил перевод", "money_requested": true},
  "contact_consent": false
}
```

Категории: `recruitment`, `fraud`, `blackmail`, `suspicious_account`, `witness`, `emergency`.

Статусы карточки:

- `new` — карточка создана;
- `under_review` — отмечена полнота записи, это не проверка полицией;
- `forwarded` — пользователь отметил, что сам обратился в МВД;
- `closed` — карточка закрыта, в том числе как спам.

В ответе нет сырого контакта и ключа файла. Контакт, если он был, возвращается маской в `contact_hint`. Полное значение попадает только в PDF, который пользователь явно скачивает.

## Срочная помощь

`POST /emergency` с телом `{"source":"miniapp"}` возвращает номера 112 и 102, текст для несовершеннолетних и дисклеймер. Звонок сервис не совершает. В `support_contacts` есть детский телефон доверия 8-800-2000-122 и телефон доверия ФСБ России 8-800-224-22-22 с сайта fsb.ru. Это подсказка, куда позвонить самому, а не передача сообщения.

## Вебхук

Нужны `BOT_MODE=webhook` и заголовок `X-Telegram-Bot-Api-Secret-Token`. Неверный секрет отвечает `401`. Тело обновления в журнал не пишется.

## Лимиты файлов

- изображение — 10 МБ, JPEG, PNG, WEBP, GIF;
- документ — 15 МБ, только PDF без скриптов и автозапуска;
- аудио — 20 МБ;
- видео — 50 МБ, MP4 или WEBM;
- не больше 8 файлов на карточку.
